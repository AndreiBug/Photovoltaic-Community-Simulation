# Inclusive Recommendation System for Energy Community Management

This repository contains the implementation of my Bachelor's Thesis:

**"Inclusive Recommendation System for Energy Community Management"**.

The project presents an energy management system for residential energy communities that share a common photovoltaic (PV) installation. It includes:

- preprocessing and cleaning of the IRISE dataset;
- photovoltaic energy production estimation;
- PV system sizing optimization using Differential Evolution;
- calculation of energy performance indicators (SC, SS, NEEG and NPV);
- a multi-agent simulation that generates energy consumption recommendations based on the community's energy balance and household presence.

The objective of the proposed system is to improve self-consumption and self-sufficiency while respecting users' preferences by providing voluntary recommendations instead of automatically controlling household appliances.
